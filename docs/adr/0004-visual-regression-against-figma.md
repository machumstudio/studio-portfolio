# 0004. Figma 시안과 픽셀 비교로 재현도 측정
- 상태: 채택 (2026-10)

## 결정
- Playwright로 390/1440/1920 전체 페이지를 찍어 Figma에서 내보낸 1x PNG와 pixelmatch로 비교한다
- 사진 영역은 `data-visual-mask`로 양쪽을 같은 색으로 덮는다 (사진은 Unsplash로 교체하기 때문)
- 시안 PNG는 제3자 사진이 섞여 있을 수 있어 레포에 올리지 않는다. 비교는 로컬에서만, 결과 수치만 README/PR에 남긴다

## 결과
"시안 재현도"를 숫자로 말할 수 있다. CI에서는 돌지 않으므로 PR 체크리스트로 보완한다.
