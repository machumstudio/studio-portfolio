# 0021. 무료 플랜 안에서 운영한다: Supabase 일시정지는 Vercel cron 으로 막고, 사진은 WebP 만, 최적화 캐시는 7일
- 상태: 채택 (2026-10-25)

## 배경
22칸에서 Vercel Hobby + Supabase 무료 + Resend 무료로 운영 배포한다. 돈을 쓰지 않고 납품하는 데모라, 무료 한도에 걸려 사이트가 멈추지 않게 해야 한다. 걸리는 곳:
- **Supabase 무료 프로젝트는 7일 동안 활동이 없으면 일시정지된다.** 작업 읽기는 `use cache`(1시간)라 방문이 있어도 DB 요청이 없을 수 있다. 정지되면 문의 저장, 관리자 화면, 캐시에 없는 작업 상세가 실패하고, 빌드(배포)도 실패한다 (빌드가 공개 작업을 읽어 미리 그린다)
- **Vercel Hobby 이미지 변환은 월 5,000회.** 넘으면 새 사진이 402 로 실패하고 alt 글자가 보인다. 변환은 캐시 MISS/STALE 마다 1회이고, 캐시 키에 폭, 품질, 원본, `Accept` 헤더(=형식)가 들어간다
  - 시드·페이지 사진(public): 31일 캐시, 재배포에도 남는다
  - 관리자가 올린 Storage 사진(바깥 주소): `minimumCacheTTL`(Next 16 기본 4시간)과 원본 `max-age`(1시간) 중 큰 값이 지나면 다시 변환한다
- 20칸에서 AVIF 를 켤지 "배포 뒤 판단"으로 남겼다

## 결정
- **일시정지 막기: Vercel cron 이 하루 한 번 `GET /api/keepalive`** (`vercel.json`, 18:00 UTC = 03:00 KST, Hobby 는 그 시각부터 1시간 안 아무 때나). 캐시 없이 공개 작업을 실제로 읽고, 실패하면 503 + 서버 로그. `CRON_SECRET` 이 있으면 Vercel 이 붙이는 `Authorization: Bearer` 만 받는다
- **이미지 형식은 WebP 만** (Next 기본값 그대로). AVIF 는 켜지 않는다
- **`images.minimumCacheTTL` 7일**

## 대안
- GitHub Actions 예약 워크플로(하루 1회 공개 읽기): 앱 코드가 필요 없지만, **공개 레포에 60일 동안 활동이 없으면 예약 워크플로가 자동으로 꺼진다.** 납품 뒤 레포가 조용해질수록 꺼질 가능성이 커진다. 운영 Supabase 주소와 키를 GitHub secrets 에도 두어야 한다. 기각
- 외부 모니터링 서비스(UptimeRobot 등)로 주기 호출: 계정과 관리할 곳이 하나 더 생긴다. 운영자가 원하면 같은 주소를 등록하면 된다 (매뉴얼에 적음)
- Supabase 유료 전환: 월 비용. 데모 범위 밖
- AVIF 켜기: 사진이 WebP 보다 약 20% 작아지지만, 형식이 캐시 키라 켜는 달에는 이미 만든 WebP 캐시를 버리고 다시 변환하고 이후에도 형식마다 변환한다. 인코딩이 느려(Next 문서 기준 약 50%) 캐시에 없는 첫 요청이 늦다. 지금 병목은 사진이 아니다: 데스크톱 성능 98~100, 모바일 흔들림의 원인은 한글 글꼴(ADR 0017). 얻는 것보다 한도와 첫 요청 비용이 커서 기각
- `minimumCacheTTL` 31일: 변환은 더 줄지만 지운 사진의 최적화 주소가 그만큼 더 열린다. 7일이면 Storage 사진 하나·폭 하나가 한 달에 많아야 약 4.4회 변환이라 충분하다

## 결과
- 매일 DB 요청이 한 번은 생겨 7일 비활성 정지에 걸리지 않는다. Vercel cron 은 배달을 보장하지 않고(놓치거나 두 번 부를 수 있음) 실패해도 다시 부르지 않는다. 하루 한 번이라 며칠 놓쳐도 7일 안에 다시 읽는다. 실패는 Vercel 대시보드 Cron Jobs > View Logs 에서 본다. 정지됐을 때 되살리는 방법은 docs/ops-manual.md
- cron 은 운영 배포에서만 돈다 (미리보기 배포, 개발 Supabase 는 해당 없음. 개발 DB 는 PR 의 Contract 워크플로가 깨운다)
- 지금 공개 페이지가 요청할 수 있는 변환 조합은 사진 30장 × 평균 10.5폭 = 317개(WebP)라 한도의 약 6%. 관리자가 사진을 많이 올려도 7일 캐시로 한 조합이 한 달에 몇 번만 변환된다. 사용량은 Vercel 대시보드 Usage 에서 본다
- 지운 사진은 최적화 주소로 최대 7일 더 열린다 (원래 주소를 알아야 하고, 주소는 UUID 라 짐작할 수 없다. ADR 0014 와 같은 성격). 바로 막아야 하면 Vercel 에서 캐시를 비운다
