# 0011. xl 브레이크포인트를 시안 노트북 프레임 폭 1440 으로 둔다
- 상태: 채택 (2026-10)

## 배경
노트북 레이아웃은 `lg`(1024)부터 시작하지만 시안 노트북 프레임은 1440 이다. 16칸에서 1024~1439 를 점검하니
시안 배치가 그대로는 들어가지 않는 곳이 있었다.
- 헤더: 가운데에 띄운 메뉴(칸 pad 30)가 로고와 겹친다 (en 1024 에서 55px)
- 푸터: CTA(폭 521 고정) 옆에 링크 4열이 들어가지 않아 한국어가 글자 단위로 세로로 꺾이고, 넘친 열을 오른쪽 장식 줄이 덮는다 (en 은 링크 4열 최소 폭이 약 760)
- About 통계 6칸: "10,000+" 가 칸을 넘는다

글자 크기처럼 폭에 비례해 줄이면 되는 것(워드마크, 통계 숫자)은 `min(시안값, vw)` 로 풀었지만,
배치를 바꿔야 하는 것(푸터 CTA 옆 → 위)은 "시안 배치가 들어가는 폭"이라는 기준이 필요하다.

## 결정
- `--breakpoint-xl: 1440px` (Tailwind 기본 xl 1280 을 바꾼다. 코드에서 xl 을 쓰던 곳은 없었다)
- 쓰는 곳은 "1024~1439 에서 시안 배치가 들어가지 않는 곳"만: `lg:` 에 좁은 배치, `xl:` 에 시안 값
  - 헤더 메뉴 칸 pad 20 → xl 30, 메뉴는 흐름 안에 두고 로고/버튼 칸을 flex-1 로 나눠 가운데 맞춤 (겹치지 않고 비킨다)
  - 푸터 CTA 위 / 링크 아래 → xl 부터 CTA | 링크
  - About 통계 카드 좌우 pad 14 → xl 24
- 1440/1920 시안 수치는 그대로라 시각 비교 결과는 바뀌지 않는다

## 대안
- Tailwind 기본 xl(1280)을 그대로 쓰기: en 푸터는 1280~1439 에서도 CTA 옆에 들어가지 않는다
- 임의 브레이크포인트 `min-[1440px]:`: 임의값 금지 규칙(ADR 0001)과 어긋나고, 같은 값이 여러 파일에 흩어진다
- 콘텐츠 폭 기준(flex-wrap 으로 자리가 모자라면 자동으로 내려가기): 언어마다 가장 좋은 지점에서 바뀌지만,
  줄이 바뀔 때 테두리(CTA 오른쪽 세로선 / 링크 위 가로선)를 맞출 수 없다
- lg 를 1440 으로 올리기: 1024~1439 가 태블릿 배치(햄버거 메뉴, 1~2열)가 되어 노트북 화면에서 너무 듬성하다

## 결과
- 브레이크포인트가 md / lg / xl / 3xl 넷이 된다. xl 은 "시안 노트북 배치가 들어가는 폭"이라는 뜻으로만 쓴다
- 1024~1439 는 ko/en 모두 e2e(e2e/responsive.spec.ts, 1024/1180/1280)로 넘침, 겹침, 줄 꺾임을 본다
