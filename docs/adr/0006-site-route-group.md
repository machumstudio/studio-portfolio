# 0006. 공개 사이트 공통 틀은 `(site)` 라우트 그룹 레이아웃에 둔다
- 상태: 채택 (2026-10)

## 배경
Header, Footer, CTA 는 공개 페이지(홈, 소개, 포트폴리오, 서비스, 문의, 작업 상세)마다 같다. 페이지마다 넣으면 빠뜨리거나 순서가 달라진다.
반면 관리자(/admin, 17칸~)와 개발용 화면은 이 틀을 쓰지 않는다. `[locale]/layout.tsx` 에 넣으면 모든 화면에 붙는다.

## 결정
- `app/[locale]/(site)/layout.tsx` 에 Header + children + Footer(CTA 포함)를 둔다. 공개 페이지는 이 그룹 아래에 만든다
- `[locale]/layout.tsx` 는 html/body, 폰트, 메시지 공급만 맡는다
- 관리자는 나중에 별도 그룹(예: `(admin)`)과 자기 레이아웃을 갖는다. 개발용 화면도 그룹 밖에 둔다
- 라우트 그룹은 URL 에 나타나지 않는다. `/`, `/en` 그대로다

## 대안
- 페이지마다 Header/Footer 직접 배치: 단순하지만 페이지가 늘수록 중복과 누락이 생긴다
- `[locale]/layout.tsx` 에 배치하고 관리자에서 숨김: 레이아웃이 경로를 알아야 해 조건문이 생긴다

## 결과
페이지 파일에는 그 페이지의 섹션만 남는다. 대신 공개/관리자 화면이 폴더로 나뉘어 새 페이지를 어느 그룹에 둘지 정해야 한다.
