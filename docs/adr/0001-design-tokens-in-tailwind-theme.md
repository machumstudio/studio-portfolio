# 0001. 디자인 토큰을 Tailwind `@theme`에 Figma 스타일 이름 그대로 둔다
- 상태: 채택 (2026-10)

## 배경
시안에는 색 스타일 26개(Absolute/Purple/Dark/Grey)와 그리드만 있고, 텍스트 스타일과 변수, 컴포넌트는 없다.

## 결정
- 색은 Figma 이름 그대로 토큰화한다 (`purple-55`, `dark-08`, `grey-70`). 디자이너와 같은 이름으로 대화할 수 있다
- 타이포는 시안 실측값으로 반응형 유틸리티 7종(`text-display` ~ `text-body`)을 만든다
- 임의 값(`bg-[#...]`, `text-[17px]`)은 린트로 막는다

## 대안
- 의미 기반 이름(`primary`, `surface`): 다크 단일 테마라 이득이 적고 시안과 이름이 어긋난다
- CSS 변수 + CSS Modules: Tailwind 대비 클래스 탐색성과 시안 대조 속도가 떨어진다

## 결과
시안 수치와 1:1로 대조된다. 라이트 테마가 생기면 의미 토큰 레이어를 추가해야 한다.
