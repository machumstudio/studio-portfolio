# 접근성

목표: WCAG 2.2 AA. 공개 사이트(ko/en)와 관리자 화면 모두.

## 색 대비

### Grey/40 글자 → Grey/50 (21칸)
시안의 Grey/40(#62646c) 글자는 어두운 배경에서 본문 기준(4.5:1)에 못 미쳤다. Lighthouse 접근성 96 의 원인.

| 쓰인 곳 | 배경 | 전: Grey/40 #62646c | 후: Grey/50 #797c86 |
|---|---|---|---|
| 홈 히어로 태그라인 (`HomeHero`) | Dark/03 #070708 | 3.41:1 | 4.83:1 |
| 후기 섹션 "전체 리뷰" (`SiteTestimonials`, 홈/소개/포트폴리오/문의) | Dark/03 | 3.41:1 | 4.83:1 |
| 후기 카드 지역 (`TestimonialCard`) | Dark/03 | 3.41:1 | 4.83:1 |
| 입력 칸 placeholder, 아무것도 고르지 않은 select (`Field`, 문의 폼/관리자 폼) | 투명(Dark/03~06) | 3.27~3.41:1 | 4.63~4.83:1 |

판단
- **토큰 값(Grey/40)을 바꾸지 않는다.** 토큰은 Figma 스타일 이름과 값을 그대로 둔다(ADR 0001). 값을 바꾸면 이름과 시안이 어긋나고 Grey/50 과 거의 같은 색이 된다
- **글자용 새 토큰도 두지 않는다.** Grey/40 의 색상 그대로 밝기만 올려 Dark/06 에서 4.5:1 을 넘는 가장 어두운 색이 #787a84 인데, 시안 팔레트의 Grey/50(#797c86)과 사실상 같다. 새 색을 만드는 대신 시안 팔레트 안의 한 단계 밝은 색을 쓴다
- 다시 쓰지 않게 ESLint 가 `text-grey-40` 을 막는다 (`eslint.config.mjs`). `bg-grey-40` 등 글자가 아닌 쓰임은 그대로 허용
- 시각 비교 차이율 변화: 페이지 전체 0.00~+0.01%p, 섹션 최대 +0.02%p (후기 섹션). 페이지별 표는 21칸 PR 본문

### 관리자 카드 배경 Dark/08 → Dark/06
관리자 화면(시안 없음)의 흐린 글자 Grey/50 이 카드 배경 Dark/08(#131316) 위에서 4.45:1 이었다.
글자 색을 Grey/70 으로 올리면 제목/본문/보조 글자의 단계가 무너져서, 카드 배경을 한 단계 어둡게(Dark/06 #0e0e10) 해 4.63:1 로 맞췄다.
카드는 테두리 Dark/12 로 구분된다. 사진 끌어 놓기 칸도 끌어 놓는 중에 배경을 밝히지 않고 테두리(보라, 실선)로 알린다.

### 푸터 워드마크
푸터의 큰 "MACHUM" 은 Dark/15(#232329) 로 Dark/03 위 1.28:1 이다. 시안의 장식(브랜드 로고타입)이라 색은 그대로 둔다
(WCAG 1.4.3 예외: 로고타입, 순수 장식). 스튜디오 이름은 저작권 줄에 글자로 있다.
글자는 DOM 텍스트가 아니라 CSS content(`decorative-text` 유틸리티, `data-text`)로 그리고 `aria-hidden` 이다.
그래서 화면 낭독기가 읽지 않고, axe/Lighthouse 명도 대비 검사도 본문 글자로 보지 않는다.
